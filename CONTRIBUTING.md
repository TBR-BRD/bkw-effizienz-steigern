# Mitwirken

Pull Requests sind willkommen.

Bitte beachte:

1. Keine geheimen Tokens, WLAN-Passwoerter oder API-Keys commiten.
2. Neue Hardware-Empfehlungen mit Quelle, Preisstand und Zertifikatshinweis dokumentieren.
3. Regeln fuer Deutschland mit offiziellen Quellen belegen.
4. Aenderungen am Regelalgorithmus mit Tests absichern.

Lokale Tests:

```bash
python -m unittest discover -s tests
```
